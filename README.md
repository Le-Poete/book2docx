# book2docx — 书本 PDF 高保真转 Word

面向书本类 PDF（教材、习题解答、专著）的 PDF → Word 转换工具。针对中文数学书的三大难点——**扫描件、数学公式、表格**——提供三种转换模式。

## 快速开始

```bash
pip install -r requirements.txt

# 自动判定模式（推荐）
python -m book2docx "书.pdf"

# 指定模式和页码范围（1-based）
python -m book2docx "书.pdf" -m editable -p 10-30 --dpi 300

# 英文/文字版 PDF
python -m book2docx "paper.pdf" -m digital
```

## 三种模式

| 模式 | 适用 | 原理 | 可编辑性 |
|------|------|------|----------|
| `faithful` | 追求 100% 原版式 | 整页高清图 + 隐形 OCR 文字层（透明文本框，可搜索可复制） | 不可编辑 |
| `editable` | 扫描书要可编辑 | 版面分割（deskew → 行/块聚类 → 区域分类）：正文 OCR 重建为可编辑文本，公式/插图/代码区域高清裁图，表格按网格线重建为原生 Word 表格 | 正文可编辑 |
| `digital` | 原生文字层 PDF | 结构化重建：字体/字号/颜色/粗斜体/对齐/行距按 PDF 还原；公式字体行自动裁图兜底 | 可编辑 |

`auto` 模式：抽样分析全书，扫描页占比 > 50% 且 OCR 文字层质量可用 → `editable`，否则 `faithful`；文字版 → `digital`。

## 设计要点（对数学书的核心处理）

1. **倾斜校正**：扫描页通常带 ~0.5° 旋转，用投影剖面法估计角度并旋转，否则斜表格线无法检测。
2. **表格**：投影 + 实心连续段双条件检测表格线（抗扫描细线断裂、防正文笔画链式误连），横线驱动定位表格；单元格文字用 **RapidOCR 重新识别**（印刷体准确率显著高于扫描仪内置 OCR 层——本样例中书内 OCR 把"舱"错成"能"，RapidOCR 全部纠正）。
3. **公式**：行级分类（中文占比/强数学符号/等式结构/上下标跨度/墨迹-文本不匹配校验），公式行整块高清裁图嵌入——OCR 永远无法完美还原数学公式，裁图是视觉零损失方案。裁图自动向墨迹扩展（补回 OCR 漏识别的符号）并清理边缘残行。
4. **代码块**：与公式同理，代码被 OCR 错字破坏后语义错误（`solve`→`8olve`），整块裁图保真。
5. **页面几何**：页面尺寸、页边距、字号、行距、首行缩进、对齐均从 PDF 几何推断。

## 已知局限

- **扫描书 OCR 源头错字**：正文行内的下标变量（如 x₆）可能被扫描仪 OCR 层错成汉字（"玉"），工具无法无中生有地修复，但公式/表格/代码区域已用图像兜底。需要逐字精准的场景请用 `faithful` 模式；`--reocr` 开关可用 RapidOCR 全页重识别减少错字（实验性，约慢 10-25s/页）。
- **可编辑模式的分页**：公式/代码/表格作为不可分割块参与 Word 流式排版，页尾遇到放不下的大块会整体换页，转换后页数约为原书的 1.2–1.8 倍（已内置页面高度预算自动压缩行距，下限 0.85）。
- **无 ToUnicode 的畸形 PDF**（某些 Word 直接导出、字体子集化且无映射）：文字层本身损坏，任何文字层工具都无法恢复，请使用 `faithful` 模式。

## 路线图

- [x] 扫描页倾斜校正（投影剖面法）
- [x] 表格线检测 + RapidOCR 单元格重识别
- [x] 公式/代码区域高清裁图 + 边缘残行清理
- [x] 插图区域检测（连通域墨迹分析，已验证图 1.1 类坐标图命中）
- [x] 页面高度预算与行距自适应压缩
- [x] 公式 OCR → Word 原生公式：`--omml` 开关（LaTeX-OCR 识别 → MathML
      → Office MML2OMML.XSL → 原生可编辑公式；**实验性**——个别公式可能
      识别错误，追求完美请用默认高清裁图）
- [x] 二遍排版：`--fit` 开关，用 Word 实测页数回填行距压缩系数
      （实测 5 页 vs 原书 4 页时自动收紧至可读下限）

## 依赖

Python 3.10+；PyMuPDF、python-docx、opencv-python、numpy、RapidOCR（onnxruntime）。
Windows 下验证工具（`book2docx.verify`）使用 Word COM（需安装 Microsoft Word）。

## 验收结果（样例书：数学建模算法与应用习题解答 第3版，178 页扫描版）

- `faithful`：3 页对比 **全数通过**——版式/公式/表格/页码与原书一致。
- `editable`：正文、表格（行列与数值全对）、公式组、MATLAB 代码全部结构化重建；受扫描 OCR 源头质量限制，正文个别错字不可避免。
